## 🚀 How to Run Locally

### Option 1: Python Web Server (Recommended)
```bash
python3 run.py
```
Then open your browser to:
- **Storefront**: `http://localhost:8088/index.html`
- **Admin Portal**: `http://localhost:8088/admin.html`

### Option 2: Direct File Launch
Simply double click or open `index.html` directly in Google Chrome, Safari, Firefox, or Edge.

## 🌐 Deploying to GitHub Pages (Free Live Website)

To publish your website live on GitHub:

1. Create a new public or private repository on [GitHub](https://github.com/new) named `miss-collection`.
2. Inside this project folder, run:
   ```bash
   git init
   git add .
   git commit -m "Launch Miss Collection luxury ladies undergarments store"
   git branch -M main
   git remote add origin https://github.com/<YOUR-USERNAME>/miss-collection.git
   git push -u origin main
   ```
3. In your GitHub repository:
   - Go to **Settings** &rarr; **Pages**.
   - Under **Build and deployment**, select **Deploy from a branch**.
   - Select Branch: `main` and folder: `/ (root)`.
   - Click **Save**.
4. Your website will be live in 1-2 minutes at:
   `https://<YOUR-USERNAME>.github.io/miss-collection/`
